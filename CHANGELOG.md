# Changelog

## 0.3.0 — 2026-11-21

### Minutes documents
- The .docx and PDF now hold the full minutes twice: first in Thai, then in
  English on a new page. The English part comes from one extra LLM call after
  the minutes are final (`MinutesJSON.english`). Action-item quotes stay
  verbatim, untranslated. If the translation fails, the Thai document is still
  written.
- Each part carries a notice that the summary was generated by AI and should
  be verified before use. The Minutes page shows the same notice.
- Discussion topics no longer list who spoke.
- Replaces the short-lived `summary_en` field.

### Reliability
- Temporary LLM provider failures (429, 5xx, timeouts, dropped connections)
  are retried with backoff instead of failing the job. Tune with
  `LLM_RETRIES` (default 5) and `LLM_RETRY_MAX_WAIT_SECONDS` (default 60).
  Errors a retry cannot fix (bad request, wrong key) still fail at once.
- A Gemini answer cut off at the output-token limit now says so, instead of
  surfacing as a schema error.
- Under `make dev` the worker restarts itself, between jobs, when any
  `sarai/*.py` file changes (`WORKER_RELOAD`). Before, editing code under a
  running worker could fail jobs with import errors.

### Web
- Theme control in the header: System (default, follows the OS appearance),
  Light, or Dark. The theme is applied before first paint.
